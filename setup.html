After you download

  1. Unzip it. Create a new public GitHub repository for the team, for example lincolnpitching.
  2. Upload everything inside the folder, including icons.
  3. Settings → Pages → Deploy from branch, main, /(root). Send the coach the link.
  4. To change settings later, edit team.js on GitHub.
  5. For weekly check-ins, follow tracking/SETUP.md in the package (about 15 minutes).
